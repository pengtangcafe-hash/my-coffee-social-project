# คูปองใหม่ทุกวันอัตโนมัติ (LINE Coupon API)

เป้าหมาย: ทุกวันตอนเช้า ระบบสร้างคูปองใหม่ในแชท LINE OA ของร้านให้เองอัตโนมัติ (เช่น ส่วนลด 10%
เฉพาะวันนั้น) ลูกค้าที่กดปุ่ม "รับเลย! แต้มสะสมแลกเครื่องดื่มฟรี" ในแอป จะเด้งเข้าแชท LINE OA
(https://lin.ee/Sra0QMy — ใส่ไว้ในแอปแล้ว) แล้วเห็นคูปองของวันนั้นเอง ไม่ต้องแก้ลิงก์ในแอปทุกวัน

## ต้องทำ 2 ขั้นตอน — ขั้นที่ 1 ต้องทำเองครับ (ต้องเข้าบัญชี LINE ของร้าน)

### ขั้นที่ 1 — สร้าง Messaging API Channel + คัดลอก Channel Access Token

**นี่คือคนละอันกับ LINE Official Account ที่สร้างไปแล้ว** — ตัวนี้คือ "ช่องทาง API" ที่ผูกกับ OA
เดิมของร้าน เพื่อให้โปรแกรม (Apps Script) สั่งงานผ่าน API ได้

1. เปิด https://developers.line.biz/console/ → ล็อกอินด้วย LINE เดียวกับที่ใช้สร้าง OA ร้าน
2. ถ้ายังไม่มี **Provider** → กด **Create a new provider** ตั้งชื่ออะไรก็ได้ (เช่น "เพียงตั้ง")
3. ในหน้า Provider → กด **Create a Messaging API channel**
4. เลือก OA ที่ผูกไว้แล้ว (เพียงตั้ง คาเฟ่ — อันเดียวกับที่สร้างบัตรสะสมแต้ม) หรือถ้าระบบให้กรอกข้อมูลใหม่
   ก็กรอกชื่อ/หมวดธุรกิจ/ประเทศไทยตามจริง → ยอมรับเงื่อนไข → **Create**
5. เข้าไปที่ channel ที่สร้าง → แท็บ **Messaging API** → เลื่อนลงหา **Channel access token**
   → กด **Issue** (ถ้าเป็น long-lived token) → **คัดลอกโค้ดที่ได้** (สตริงยาวๆ)

> Token นี้สำคัญมาก ห้ามแปะในแชทสาธารณะ/โพสต์ที่ไหน — ส่งให้ผมทางแชทนี้ได้ (ผมจะเก็บไว้ใน
> Script Properties ฝั่งเซิร์ฟเวอร์เท่านั้น เหมือนที่ทำกับ Slack Webhook — ไม่ฝังในโค้ดแอปที่ลูกค้าเห็น)

### ขั้นที่ 2 — ส่ง Channel Access Token มาให้ผม

ผมจะ:
1. ทดสอบยิง API สร้างคูปองจริง 1 ใบ เพื่อยืนยันว่ารูปแบบ request ถูกต้อง (ก่อนตั้ง auto ทุกวัน)
2. เพิ่มฟังก์ชันในไฟล์ `orders-notify/Code.gs` เดิม (สคริปต์เดียวกับที่ใช้แจ้งเตือน Slack) —
   สร้างคูปองใหม่ + หมดอายุคูปองเก่าของเมื่อวาน ตั้ง **time-driven trigger ให้รันทุกวันตอนที่คุณ
   กำหนด** (เช่น 07:00 ก่อนร้านเปิด)
3. ให้คุณช่วยบอกรายละเอียดคูปอง (ส่วนลดกี่ % หรือกี่บาท / มีเงื่อนไขขั้นต่ำไหม / ใช้ได้ถึงกี่โมง)

## ข้อควรรู้

- คูปองที่สร้างผ่าน API จะไปโผล่ในแชท OA ให้ลูกค้าเห็นเอง (LINE จัดการเรื่องกันสแปม/จำกัดการแลกซ้ำให้
  อยู่แล้ว เหมือนบัตรสะสมแต้ม)
- ปุ่มในแอปไม่ต้องแก้ทุกวัน เพราะชี้ไปที่แชท OA เฉยๆ ไม่ได้ชี้ไปที่คูปองใบใดใบหนึ่งโดยตรง
- ยังไม่ได้ยืนยัน rate limit / ข้อจำกัดของ LINE Coupon API 100% เพราะหน้าเอกสารทางการบล็อกการเข้าถึง
  แบบอัตโนมัติของผม — ขั้นตอนแรกที่ผมทำหลังได้ token คือทดสอบยิงจริง 1 ครั้งก่อน เพื่อดู response จริง
  แล้วค่อยตั้ง automation
