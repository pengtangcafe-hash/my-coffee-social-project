# เชื่อมปุ่มสะสมแต้มเข้ากับ LINE Official Account

ปุ่ม "รับเลย! แต้มสะสมแลกเครื่องดื่มฟรี" ในแอปเมนู ต้องลิงก์ไปที่ **บัตรสะสมแต้ม (Point Card)**
ของ LINE Official Account — เป็นฟีเจอร์ในตัว LINE เอง ไม่ต้องสร้างระบบกันสแปมเอง เพราะ LINE
หมุน QR/ลิงก์ของบัตรให้เองอยู่แล้ว (ตอบคำถามที่คุณถามไว้ก่อนหน้านี้)

ต้องทำ 2 ขั้นตอน — **ขั้นที่ 1 ต้องทำเองครับ** (ต้องยืนยันตัวตนด้วยเบอร์โทร/บัญชี LINE ของร้าน
ผมทำแทนไม่ได้) ขั้นที่ 2 ส่งลิงก์มาให้ผมได้เลย

---

## ขั้นที่ 1 — สร้าง LINE Official Account + เปิดบัตรสะสมแต้ม (ฟรี)

1. เปิด https://www.linebiz.com/th/entry/ → **สร้างบัญชี LINE Official Account**
   (ใช้เบอร์โทรของร้าน ยืนยันผ่าน SMS)
2. ตั้งชื่อบัญชี เช่น "เพียงตั้ง คาเฟ่" → เลือกหมวดธุรกิจ "ร้านกาแฟ/เครื่องดื่ม" → เลือกแพ็กเกจ
   **Free plan** ได้เลย (พอสำหรับบัตรสะสมแต้ม)
3. เข้า **LINE Official Account Manager** (https://manager.line.biz) → เลือกบัญชีร้าน
4. เมนูซ้าย **หน้าแรก (Home)** หรือ **เครื่องมือ (Tools)** → หา **"บัตรสะสมแต้ม" (Point Card)**
   → กด **สร้างบัตรสะสมแต้ม**
5. ตั้งค่าบัตร:
   - จำนวนแต้มที่ต้องสะสมก่อนแลกได้ (เช่น 10 แต้ม = 1 แก้วฟรี)
   - ดีไซน์บัตร (สี/โลโก้ร้าน — ใส่ธีมสีแบรนด์ได้)
   - เงื่อนไขการให้แต้ม (พนักงานสแกน QR ที่เคาน์เตอร์ให้แต้มลูกค้าทุกครั้งที่ซื้อ)
6. เมื่อสร้างเสร็จ LINE จะให้ **ลิงก์/URL ของบัตรสะสมแต้ม** (กดปุ่ม "แชร์" หรือ "Share" ในหน้าบัตร
   จะเห็นลิงก์ที่ขึ้นต้นด้วย `https://liff.line.me/...` หรือคล้ายกัน)

> บัตรสะสมแต้มของ LINE ผูกกับ LINE OA เท่านั้น — คนละระบบกับ Slack ที่ใช้แจ้งเตือนออเดอร์อยู่ตอนนี้
> (Slack ยังใช้แจ้งเตือนออเดอร์ต่อได้ตามปกติ ไม่ต้องเปลี่ยน)

## ขั้นที่ 2 — เชื่อมเข้าแอป (ผมทำให้)

ส่งลิงก์บัตรสะสมแต้มจากขั้นที่ 1 มา แล้วผมจะไปแก้ค่าคงที่ `kLineStampUrl` ใน
`lib/services/line_stamp.service.dart` ให้ชี้ไปที่ลิงก์นั้น แล้ว build + deploy ใหม่ให้ครับ

ระหว่างที่ยังไม่มีลิงก์ ปุ่มจะซ่อนอยู่ในแอป (ไม่โชว์ปุ่มเปล่าที่กดแล้วไม่มีอะไรเกิดขึ้น) — โผล่มาเองทันที
ที่ผมใส่ลิงก์จริงให้
