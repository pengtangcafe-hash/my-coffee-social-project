# แจ้งเตือนออเดอร์เข้า Slack + บันทึกลง Google Sheet

ทุกครั้งที่ลูกค้ากด "สั่งรายการและชำระเงิน" ในแอปเมนู ระบบจะ:
1. บันทึกออเดอร์ลง Google Sheet (โต๊ะ / เวลา / รายการ / จำนวนแก้ว / ยอดรวม)
2. ส่งข้อความแจ้งเตือนเข้าช่อง Slack ทันที

ต้องทำ 3 ขั้นตอน — **ขั้นที่ 1 กับ 2 ต้องทำเองครับ** (ต้องเข้าบัญชี Slack/Google ของร้าน ผมทำแทนไม่ได้) ขั้นที่ 3 บอกผมได้เลย

---

## ขั้นที่ 1 — สร้าง Slack Incoming Webhook (ฟรี, 5 นาที)

1. เปิด https://api.slack.com/apps → **Create New App** → **From scratch**
2. ตั้งชื่อแอป (เช่น "เพียงตั้ง ออเดอร์") → เลือก Workspace ของร้าน (ถ้ายังไม่มี workspace ให้สร้างที่ https://slack.com/get-started ก่อน ฟรี)
3. เมนูซ้าย: **Incoming Webhooks** → เปิดสวิตช์ **Activate Incoming Webhooks**
4. กด **Add New Webhook to Workspace** → เลือกช่อง (channel) ที่จะให้แจ้งเตือนเข้า (เช่นสร้างช่องใหม่ชื่อ `#ออเดอร์`) → **Allow**
5. คัดลอก **Webhook URL** ที่ได้ (ขึ้นต้นด้วย `https://hooks.slack.com/services/...`) — เก็บไว้ใช้ในขั้นที่ 2

> ติดตั้งแอป Slack บนมือถือ + เปิดแจ้งเตือนของช่องนั้นไว้ จะได้เห็นออเดอร์เด้งทันทีที่มีลูกค้าสั่ง

## ขั้นที่ 2 — ติดตั้ง Apps Script (บันทึกชีท + ส่งต่อ Slack)

1. เปิด https://sheets.google.com → สร้างสเปรดชีตใหม่ ตั้งชื่ออะไรก็ได้ (เช่น "ออเดอร์เพียงตั้ง") — ใช้ Gmail เดิมของร้านได้เลย
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมทิ้ง แล้ววางเนื้อหาทั้งหมดจากไฟล์ **`Code.gs`** (ในโฟลเดอร์นี้) → บันทึก (Ctrl+S)
4. ตั้งค่า Slack webhook: เมนูซ้าย ⚙️ **Project Settings** → เลื่อนลงหา **Script Properties** → **Add script property**
   - Property: `SLACK_WEBHOOK_URL`
   - Value: (วาง Webhook URL จากขั้นที่ 1)
   - กด **Save script properties**
5. กลับไปแท็บ **Editor** → มุมขวาบน **Deploy → New deployment**
6. ไอคอนเฟือง ⚙️ → เลือก **Web app**
7. ตั้งค่า:
   - **Execute as:** Me (อีเมลคุณ)
   - **Who has access:** **Anyone** ← สำคัญ (ให้แอปเมนูเรียกได้)
8. กด **Deploy** → อนุญาตสิทธิ์ตามขั้นตอน (เลือกบัญชี → Advanced → ไปต่อ → Allow)
9. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`) — ส่งให้ผมได้เลย

> แก้สคริปต์ภายหลัง: ต้อง **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** ทุกครั้ง ไม่งั้น URL เดิมยังรันโค้ดเก่า

## ขั้นที่ 3 — เชื่อมเข้าแอป (ผมทำให้)

ส่ง Web app URL จากขั้นที่ 2 มา แล้วผมจะไปแก้ค่าคงที่ `kOrdersWebhookUrl` ใน
`lib/services/order.service.dart` ให้ชี้ไปที่ URL นั้น แล้ว build ใหม่ให้ครับ

## โครงสร้างชีท "ออเดอร์" (สร้างอัตโนมัติตอนออเดอร์แรกเข้ามา)

| เวลา | โต๊ะ | รายการ | จำนวนแก้ว | ยอดรวม | รายละเอียด (JSON) |
|---|---|---|---|---|---|

เรียงตามเวลาที่บันทึกจริง (แถวใหม่อยู่ล่างสุดเสมอ) — ดูได้ว่าโต๊ะไหนสั่งก่อน/หลัง กี่แก้ว รวมเป็นเงินเท่าไหร่

## ความปลอดภัย
- Web app URL ฝังอยู่ในโค้ดแอป (เห็นได้ถ้ามีคนดู source) — แต่ทำได้แค่ "ส่งออเดอร์เข้า" อย่างเดียว (endpoint นี้ไม่มีการอ่านข้อมูลออกมา) ความเสี่ยงคือมีคนยิงออเดอร์ปลอมเข้าชีทได้ ถ้ากังวลจุดนี้บอกได้ ทำเพิ่มเป็นระบบยืนยันตัวตนง่ายๆ ได้
- Slack Webhook URL เก็บใน Script Properties (ฝั่งเซิร์ฟเวอร์เท่านั้น) ไม่หลุดออกมาที่โค้ดแอปหรือเบราว์เซอร์ลูกค้าเลย
